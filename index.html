    Binary Entropy

    Entropy measures how unpredictable a yes/no event is. Enter the probability p of one outcome (0 to 1). Fractions like 1/3 work too.

    Formula H(p) = −p · log₂(p) − (1 − p) · log₂(1 − p)
    The answer is in bits. H(0) = H(1) = 0, and the maximum is H(0.5) = 1 bit.

    Differentiation

    Find the derivative of f(x). Write powers as x^2, products as 3x or 3*x, and use sin(x), cos(x), tan(x), e^x, ln(x), sqrt(x).

    Rules used Power: d/dx xⁿ = n·xⁿ⁻¹
    Product: (u·v)′ = u′v + uv′
    Quotient: (u/v)′ = (u′v − uv′) / v²
    Chain: d/dx f(g(x)) = f′(g(x)) · g′(x)
    sin x → cos x, cos x → −sin x, eˣ → eˣ, ln x → 1/x

    Integration

    Find the area under f(x) between two x values. The calculator also tries to find the antiderivative F(x).

    Formulas ∫ xⁿ dx = xⁿ⁺¹ / (n + 1) + C (n ≠ −1)
    ∫ 1/x dx = ln|x| + C
    ∫ sin x dx = −cos x + C, ∫ cos x dx = sin x + C, ∫ eˣ dx = eˣ + C
    Definite integral: ∫ₐᵇ f(x) dx = F(b) − F(a)
    Simpson's rule (used for the number): ∫ ≈ (h/3) [f₀ + 4f₁ + 2f₂ + … + fₙ]

    Limits

    See what f(x) gets close to as x approaches a value. Type inf for infinity.

    Idea lim x→a f(x) = L means f(x) gets closer and closer to L as x gets closer to a.
    A two-sided limit exists only when the left-hand and right-hand limits agree.
    The calculator tries x = a ± 0.1, 0.01, 0.001, … and checks where the values settle.
